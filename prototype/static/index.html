🤖 About the System

This prototype demonstrates an agent-based pipeline for cloud-native incident diagnosis.

On each run, the agent:

  1. Receives the alert
  2. Fetches metrics from Prometheus
  3. Queries logs from Elasticsearch
  4. Retrieves docs via RAG
  5. Generates a report with Gemini AI
