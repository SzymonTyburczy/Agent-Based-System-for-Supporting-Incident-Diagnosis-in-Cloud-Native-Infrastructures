# Agent-Based System for Supporting Incident Diagnosis in Cloud-Native Infrastructures

## Overview
The objective of this engineering thesis is to design and implement a prototype information system that supports the incident diagnosis process in distributed cloud-native infrastructures. The system will utilize operational telemetry data originating from multiple sources, such as metrics, logs, and system events, in order to automatically correlate information and generate structured diagnostic reports.

## Key Features
- **Telemetry Data Integration**: Utilizes metrics, logs, and system events from various monitoring sources.
- **Agent-Based Architecture**: Operates within a cloud-native environment to continuously monitor and analyze the state of the infrastructure.
- **Retrieval-Augmented Generation (RAG)**: Retrieves domain-specific technical knowledge from documentation to assist in the diagnosis process.
- **Automated Diagnostic Reports**: Generates structured reports containing potential root causes of incidents and recommended remediation actions.
- **Decision Support System**: The level of system autonomy is limited to decision support only; the system will not execute remediation actions automatically.

## Planned Workflow
1. **Alert Reception**: The system receives alerts generated by standard monitoring tools.
2. **State Analysis**: Agents analyze the current state of the infrastructure based on telemetry data.
3. **Knowledge Retrieval**: Uses RAG to find relevant solutions and context from technical documentation.
4. **Report Generation**: Outputs a comprehensive diagnostic report outlining what went wrong and how to fix it.

*Note: Specific implementation details, technology stack, and installation instructions are currently in the planning phase and will be updated in future iterations.*

## Validation
The proposed solution will be validated using predefined incident scenarios. Its effectiveness will be evaluated through an analysis of the completeness and usefulness of the generated diagnostic reports.
